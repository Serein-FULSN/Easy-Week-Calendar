因为想要一个就是只简短看看这两周都干什么然后让ai搓了一个插件<br>
Easy-Week-Calendar就这样出来了<br>
首先，在想要添加Calendar的笔记开头写上这样的一段话：<br>
  week:2026.09.01 标题<br>
  其中：week:2026.09是你想要添加视图的月份，后面的01是你想要添加视图的周数（一般都是01~04周这样子），随后空格，加上你想要显示的这周的简短内容<br>
接着回车，就能显示出上中下三周的周视图，加粗高亮的为本周，相邻周的简短介绍会在相邻周简短介绍存在后更新到最右侧的栏内<br>
